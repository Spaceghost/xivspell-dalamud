2026-10-31 / concurrent additive MCP

Slow mod requests no longer block unrelated spellbook reads or MCP ping.
Four workers share one upstream session and correlate responses by request ID,
preserving approval/ticket ownership. Late responses cannot satisfy newer
requests and timed-out actions are never automatically replayed.
Source saves remain ordered and use atomic file replacement;
owned transport workers close when the server exits. Live tool schemas were
compared with the generated API: all 172 still match.

2026-10-29 / 0.1.0 beta

Native spell command bar in the player casting area, with spell-name Tab
completion, expansions, macros, dot repeat, and source-bound game icons.
Neovim is the Lua editor; an independent user service hosts spell programs.
Starter Arcanist deck uses action IDs queried from the running game.
Generated LuaLS definitions cover the live 172-tool XivMcp catalogue.

starting a process for every action. Typed lifecycle hooks support extensions.

Player playtest: native input, completion, expansions, repetition and live casts
worked. The game accepted Radiant Aegis and Physick requests, with observed
request times of 30–36 ms. Controller casting remains under investigation;
