STEAM CONTROLLER / STREAMED SPELLSTRINGS

The 2026 Steam Controller connects to the streaming client. Moonbeam translates
its two trackpads into individual keyboard taps; it forwards buttons, sticks,
triggers and gyro through the normal PlayStation-style controller path.
XivSpell receives ordinary keyboard input and does not need raw USB access.

CLIENT SETUP

Use the Moonbeam build containing the radial trackpad keyboard and Triton
driver. Enable Settings > Gamepad > Use Steam Controller trackpads as a radial
keyboard (enabled by default). Connect by USB or the wireless dongle.

Launch Moonbeam directly, or disable Steam Input for its Steam shortcut so
Moonbeam can see both native trackpads. Remove the older pad-to-stick mappings.
Do not open XivSpell's F8 modal wheel for this layout.

  Left pad outer ring   Select ABCD, EFGH, IJKL, MNOP, QRST, UVWX, YZ-' or 0-9
  Left pad center       Select tools: period, greater-than, Backspace, Enter, Esc
  Right pad outer ring  Aim at a character; lift to type it on the rhythm pulse
  Right pad center      Tap and lift for a space
  Sticks / face buttons / triggers / gyro  Normal gamepad behavior
  R2 + A                Repeat the weave (PlayStation R2 + Cross)
  R2 + B                Continue the weave (PlayStation R2 + Circle)

Touching the pads displays the guide in Moonbeam; lifting both hides it.
The selected letter group stays selected until changed. A held thumb never
repeats letters. Focus loss or disconnect cancels the unfinished gesture.
Type i to enter weaving, then spell the full target and spell name on the beat.

Spell "tank physick", including its space. Then spell "physick"; it keeps the
tank target. "self physick" changes the target for that and following spells.
DEFAULT in the target picker or clearing the weave resets target memory. Undoing
a spell that changed the target restores the preceding aim.

OLDER MODAL WHEEL

F8 or /xivspell radial still opens XivSpell's older stick-operated wheel. It
temporarily captures the controller and is separate from Moonbeam's keyboard.
L3+R3 no longer opens it automatically. The card composer is /xivspell pad.

VALIDATION AND PORTABILITY

The keyboard channel is independent of the host OS. Moonbeam has desktop
clients for Linux, Windows and macOS; its native mobile Android/iOS clients
are not implemented by this change. A portable touch-to-key state machine
does not by itself establish mobile controller access or ship a mobile app.

Software tests cover the radial gestures and XivSpell target memory. The
physical Steam Controller is on a separate streaming device, so end-to-end
USB/dongle routing still needs a client test. Move and rotate the camera while
typing a phrase; each lift should enter one letter without affecting either
stick. Alt-tab while holding a pad, then return and lift: it must not type.
